# LSCO TDCJ Intake

Machine-readable intake, OCR review, admissions export, and archive system for the LSCO TDCJ Application Rev. 02/2026.

## Current build target

1. Load locked JSON maps.
2. Load Admissions headers.
3. Detect page fiducials.
4. Generate field overlays.
5. Build review/export/archive pipeline.

No production student data should be committed to this repository.
